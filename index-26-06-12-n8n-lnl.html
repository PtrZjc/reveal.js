Part II

n8n tips I wish I knew sooner

use Sub-workflows as Pure Functions

Isolate business logic and ensure predictable data outputs and testability

Prevent loop node termination

Ensure all errors and branches inside are handled correctly

use Data Tables as a Local Cache

Use built-in n8n mechanism when persistence is needed inside a workflow

Time & Date Handling

String variables are native date objects under the hood thanks to Luxon library

use No-Op Nodes as Structural Anchors

Maintain clean graph architecture and immutable reference points

Externalize Workflow Configuration

Consider using simple controlled spreadsheets to store configuration and constants.

use Global Exception Handler workflow

Ensure workflow error visibility by redirecting all errors to monitored channel

Consider Telegram as reporting channel

Due to very high limits and ease of integration (the private use only)
